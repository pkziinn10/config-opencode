# Regras Globais do Usuario

Hierarquia: 1. Regras do workspace (projeto) > 2. Regras Globais (este arquivo)

## Regras

1. Nao implemente nada sem antes perguntar para o usuario analisar.
2. Responda sempre em portugues-br.
3. Quando o usuario pedir algo relacionado ao github, use git flow profissional (main > develop > feature/ *, release/ *, hotfix/ *).
4. Em relacao a commits no github, mostre sempre as opcoes em portugues-br e em ingles para o usuario escolher.
5. No plano de implementacao, quando criar, auxilie com o codigo.
6. Sempre que criar um plano, adicione ele no diretorio .docs. Se nao existir, crie.
7. Nao utilize emotes/emojis.
8. Sempre siga estas regras. Hierarquia: 1. Regras do workspace, 2. Regras Globais (este arquivo).
9. NAO faca nada em relacao a comentario, criacao de PR, commit ou push sem antes eu confirmar explicitamente. Apresente o conteudo/acao e aguarde minha aprovacao.
